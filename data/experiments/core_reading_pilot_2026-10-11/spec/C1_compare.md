# C1 — core-role comparison (core-reading pilot, 2026-10-11)

Each item shows a list of "shared" biological pathways and two independent readings of them, each written by someone who saw the shared pathways together with a DIFFERENT set of additional pathways (not shown here). Each reading gives a theme and the role the shared pathways play in that theme.

Decide whether the two readings frame the SHARED pathways in the same way:
- "same": the shared pathways play the same role in both themes; any difference is wording or a minor addition.
- "partly": the role overlaps but one reading puts clear emphasis on a different aspect, function or context.
- "different": the shared pathways are read as serving clearly different biology, function or context.

Judge by biological meaning, not wording.

Return one JSON object per item: {"item_id": "...", "verdict": "same"|"partly"|"different"}
