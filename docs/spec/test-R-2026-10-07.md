## Scores, for every candidate grouping g of size 3–9 that has support ≥ 0.33 (the existing fixed-cut families, real and scrambled)

- **h_full(g):** the median, over runs where g is found, of the Ward height at which g's cluster forms.
- **G_loo (PRIMARY, Aviyah's leave-one-out):**
  - Look at each run where EXACTLY one member of g is not sampled. Call the present members R.
  - Starting from the smallest cluster containing R, walk up to the first cluster that contains any pathway outside g. h_out(r) = its height.
  - G_loo(g) = the median over those runs of h_out(r) / h_full(g).
  - Groupings with fewer than 10 such runs are scored on what they have, and the count is reported.
- **G_life (SECONDARY, classic lifetime):** the median, over runs where g is found, of (the height of g's parent) / h_full(g).

## Gate and calibration

- Gap gate = support ≥ 0.33 AND G_loo ≥ t_s.
- t_s is set per size stratum (3, 4, 5, 6, 7–9) on seeds 3001–3003: the lowest value whose scrambled/real ratio is ≤ 0.01.
- For sizes ≥ 10, the build's current rule is unchanged.
- Report the same gate with G_life, as secondary.
- **Single-t version** (the more elegant form): one gap cutoff t for ALL sizes 3–9. It is the lowest t whose scrambled/real ratio is ≤ 0.01 on 3001–3003. Report it with every check below, beside the per-size version.
