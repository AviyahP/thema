# name-v3, the twenty hardest names to defend

*Generated 27 Sep 2026 from the 861 named themes of `recurrent_dag_consensus_centred`. Ranked by
the share of the name's content words that appear NOWHERE in any member's name or description --
the words the members do not support. Ties break on size. This is a mechanical proxy for over-reach,
not a verdict: a word can be absent and still correct (`mitotic` for a theme of spindle terms), and
a name can be fully supported and still wrong. It finds the places worth your eyes.*
