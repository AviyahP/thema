Themes come from a frozen ontology built before any experiment is analysed, so theme-level testing is no more circular than standard over-representation analysis. The ontology on this page is real: … pathways from … databases, described by an LLM from each pathway's curated text and gene list, embedded with BioLORD-2023 and cut from one Ward tree at three depths. What is designed but not built, and therefore shown as not computed throughout: soft membership, so that a pathway which is half proliferation and half DNA repair is recorded as both rather than assigned to one; Benjamini–Hochberg significance across the whole tree in one family, with attribution tests in their own family; and the written theme names that will replace the keyword labels. github.com/AviyahP/thema
